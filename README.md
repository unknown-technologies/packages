Archlinux Packages
==================

This repository contains Archlinux PKGBUILD files for various packages which
may or may not be useful for you.

To build these packages, clone this repository and run `makepkg` in the
relevant subfolders.

Since none of the referenced projects have proper releases, these PKGBUILD
files always build the latest git commit. Technically the package names should
have `-git` in their name, but since there are no releases anyway, the `-git`
part is not included in the package names.
